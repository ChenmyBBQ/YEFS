# YEFS 功能点文档

## 1. 文档说明

本文档用于梳理 YEFS 当前对外呈现的功能模块、能力边界和实现状态，面向产品、项目管理和协同开发成员。

为避免把菜单入口误判为已完整落地能力，本文档对功能状态采用以下分级：

- 已实现：已有明确页面、类或插件逻辑支撑，具备可运行闭环。
- 部分实现：已有框架或部分交互，但能力仍依附于通用页面或尚未形成完整闭环。
- 占位/规划中：目前主要体现为菜单入口、路由或设计意图，尚未看到对应独立实现。

## 2. 功能总览

当前菜单体系定义在 `src/qml/YefsGlobal.qml`，共包含以下一级模块：

- 地图
- 航线规划
- 空域管理
- 数据管理
- 地图工具

同时，主窗口还提供以下辅助入口：

- 设置
- 关于
- 导航模式切换

## 4. 地图模块

### 4.1 地图主页面

地图主页面为 `src/qml/Home/MapPage.qml`，是当前系统最核心的业务承载页。

已实现能力包括：

- 地图加载与显示。
- 地图样式切换。
- 基础相机交互：缩放、平移、旋转、俯仰、复位、定位默认区域。
- 状态栏坐标显示。
- 图层面板入口。
- 在线地图面板入口。

相关支撑模块包括：

- `MapLibreEngine`
- `MapSettings`
- `CoordinateConverter`
- `SettingsManager`

### 4.2 地图交互能力

从 `MapPage.qml` 和 `MapLibreEngine` 可以确认当前已具备以下交互：

- 左键点击地图并上报地理坐标。
- 鼠标悬停时进行坐标转换显示。
- 滚轮缩放。
- 左键拖动平移。
- 右键拖动调整旋转与俯仰。
- 通过消息总线向其他模块广播地图点击事件。

状态判定：已实现。

### 4.3 图层与在线地图入口

从 `MapPage.qml` 可见当前已经提供：

- 图层管理面板入口。
- 在线地图面板入口。

从 `Implementation-Summary.md` 和主工程代码可以判断：

- GeoJSON、GPX、KML 解析器已接入。
- `MapSourceManager` 与 `OnlineMapProviderManager` 已存在。
- 在线地图提供商框架已具备。

但从当前菜单和页面组织看，这部分能力更偏“基础能力已接入、产品化交付尚未完全展开”。

状态判定：部分实现。

## 5. 空域管理模块

### 5.1 模块概述

空域管理是当前最成熟的业务模块，主要由 `plugins/AirspaceManagerPlugin/` 提供。

它覆盖了：

- 空域创建。
- 空域绘制交互。
- 空域实时预览。
- 空域属性编辑。
- 空域持久化存储。
- 空域再次加载与地图显示。

### 5.2 新建空域

入口来源：

- `YefsGlobal.qml` 中的 `NewAirspace`
- `Main.qml` 中的菜单点击处理

实际能力：

- 通过消息总线进入空域创建模式。
- 在地图页面上进行图形绘制交互。
- 绘制完成后进入属性编辑与保存流程。

状态判定：已实现。

### 5.3 空域绘制能力

根据 `DrawingController.cpp` 和 `ShapeGenerator` 相关逻辑，当前支持的图形类型包括：

- 矩形
- 正方形
- 圆形
- 多边形
- 边界线
- 圆环
- 圆弧
- 扇形
- 扇环

当前绘制流程包括：

1. 进入绘制状态。
2. 响应地图点击采点。
3. 响应地图悬停生成动态预览。
4. 达到最少点数后自动完成，或手动点击完成。
5. 进入编辑和保存流程。

状态判定：已实现。

### 5.4 空域数据管理

根据 `AirspaceManagerPlugin.cpp` 可确认空域模块具备：

- 数据库存储。
- 启动时加载已有空域。
- 按 GeoJSON 图层重新添加到地图。
- 通过 `AirspaceModel` 进行模型管理。

状态判定：已实现。

### 5.5 空域管理页与侧边面板

插件已暴露以下 QML 入口：

- 主页面：`AirspaceManagerPage.qml`
- 设置页：`AirspaceSettings.qml`
- 工具栏：`AirspaceToolbar.qml`
- 侧边面板：`AirspaceListPanel.qml`

但从主工程当前菜单组织和页面承载方式来看，主体验证重点仍在地图页面上的绘制与管理闭环，而非完全独立的产品化管理后台页面。

状态判定：部分实现到已实现。

## 12. 结论

从产品能力现状看，YEFS 当前最成熟的两条主线是：

- 地图展示与基础 GIS 交互
- 空域管理插件驱动的业务闭环

菜单体系已经提前铺开，覆盖了航线规划、数据管理和地图工具等多个方向，但其中相当一部分仍处于入口级设计或能力预留阶段。

因此，当前项目更适合被定义为：

- 已完成地图底座和插件化业务雏形。
- 已形成空域管理这一条代表性业务闭环。
- 其余业务模块正在等待进一步页面拆分、控制器实现和产品化完善。
